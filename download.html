Download the Wyltl ToolChain




Desktop versions of the Wyltl Interpreter are available for download below. The current version is Release Three.

The desktop versions of Wyltl are command line based applications. They must be executed with the command line (Windows) or the system terminal (Linux).






Release Log


Release Three - March 2025 : The final reference release of Wyltl with bugfixes and performance improvements to the interpreter and compiler. Additionally, the Wyltl VSCode Extension was released and the REPL recieved a much needed facelift!

Release Two - February 2025 : The release of a stable version of the Wyltl Compiler. Considerable improvements to the Wyltl standard library. JavaScript interoperability and more!

Release One - December 2024 : The 'proof of concept' in regards to the Wyltl Development Project. This release contains a stable version of the Interpreter, with many of the features present in the language fully realized.
